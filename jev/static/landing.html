One harness.
Every agent superpower.

Urai is an OpenCode-class agent harness with its own local models: verify-first agents, parallel swarm, conductor orchestration, browser, skills, memory, scheduler — served over an OpenAI-compatible API. Zero cost, no keys, privacy by default.

Open the appAndroid APKUse the API

Harness

Not a chatbot — a runtime that plans, acts, verifies.

Verify-first agent

Plan → tool → observe → verify → correct, with budgets and full traces.

Conductor

Thinker splits, workers run in parallel, verifier merges. Fugu-style roles, local pool.

Swarm

Fan-out up to 8 tasks across workers with isolated failures.

Browser + approvals

Human-like automation; auth fields pause for your approval, never fail.

Memory + focus

Active memory with recency scoring and a focus anchor injected every run.

Scheduler + sessions

Cron-style background agents and server-side conversations that survive restarts.

OpenAI-compatible API

Point any OpenAI client at Urai. Same shapes, zero cost.

export URAI=https://urai.daddyai.online
curl $URAI/v1/chat/completions \
  -H "Authorization: Bearer urai_YOUR_TOKEN" \
  -H Content-Type:application/json -d '{
  "model": "urai",
  "messages": [{"role":"user","content":"Hello Urai"}]}'

Agents, tiers and tools: POST /agent (tier, plan, session) · POST /agent/swarm (parallel/conductor) · POST /tools · full reference in docs.

CLI

Remote-first: nothing heavy installs locally.

git clone --depth 1 https://github.com/etside/urai.git ~/.local/share/urai
ln -sf ~/.local/share/urai/bin/urai ~/.local/bin/urai
urai login 856777
urai ask --remote "hello"        # chat
urai agent --remote "do research" --plan   # propose first
urai swarm --remote "task one" "task two"  # fan out
