Capabilities
Everything an AI needs

Built with production reliability, runs on consumer hardware, extends to cloud when you want.

🧠
Local LLM
Qwen3 family (0.6B–8B) via llama.cpp. GPU offload when available. No API keys, no cloud, full privacy.
🎤
Voice (STT + TTS)
faster-whisper STT + Kokoro TTS locally. AWS Polly neural + Transcribe as free-tier fallback. Bengali & English first-class.
🌐
Browser Automation
Playwright-powered computer use. Screenshot → perceive → click/type autonomously. Session recovery on crash.
📚
Knowledge Wiki
3-tier memory: session cache, mid-term sessions, permanent wiki pages. BM25 search. Obsidian-compatible wikilinks.
🤖
Named Agents
Persistent agents with their own instructions, tools, memory, and schedule. Runs tasks automatically on cron.
💻
Vibe Code
Natural language → write code → run → iterate loop. Works on real projects. Tool-guarded execution.
🔬
Deep Research
IterResearch-style: plan → multi-hop search → fetch pages → synthesize. All local, Perplexity-quality.
🔌
MCP + Plugins
Full MCP server and client. OpenClaw-style plugin marketplace. 16 built-in tools + toolpacks.
Get started
One command install
curl -fsSL https://raw.githubusercontent.com/etside/urai/main/install.sh | bash
docker run -p 8777:8777 -e URAI_MASTER_KEY=$(openssl rand -hex 32) -v urai-data:/app/data ghcr.io/etside/urai:v3
pip install urai && urai api --port 8777
