Ollama / GGUF import

        
Import any Urai GGUF into Ollama (Android app or desktop) for fully offline use.

        
Loading…

        

          
Import a custom GGUF into Ollama

          
# 1. Download any GGUF from the models list above
# 2. Create a Modelfile:
echo 'FROM ./your-model.gguf' > Modelfile
echo 'PARAMETER num_ctx 4096' >> Modelfile
# 3. Import:
ollama create my-model -f Modelfile
# 4. Run:
ollama run my-model

          
On Android: use the Ollama Android app → import GGUF from storage → same Modelfile approach via termux or adb.
